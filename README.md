# 🚢 Titanic Survival Prediction App

This is a Machine Learning web application built using **Python, Scikit-Learn, and Streamlit**. 

### 💡 Features:
- Predicts whether a passenger would survive the Titanic disaster based on inputs like Age, Ticket Class, Fare, and Gender.
- Built using a **Random Forest Classifier** model.
- Deployed live on Streamlit Cloud.
